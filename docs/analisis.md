### 1.1 Identificación de clases y objetos

| **Clase**            | **Tipo**    | **Atributos principales**                                   | **Responsabilidades (métodos)**                                                                                                 | **Justificación**                                                               |
|----------------------|-------------|-------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------|
| **Persona**          | Abstracta   | nombre, apellido, telefono, correo                          | nombreCompleto(), mostrarDatos()                                                                                                | Clase padre genérica que comparte datos comunes para dueños y veterinarios      |
| **Dueño**            | Concreta    | direccion                                                   | mostrarDatos(), nombreCompleto()                                                                                                | Representa al cliente responsable legal de una o varias mascotas                |
| **Veterinario**      | Concreta    | cedulaProfesional, especialidad                             | mostrarDatos(), nombreCompleto()                                                                                                | Personal médico encargado de atender citas y generar ingresos                   |
| **Recepcionista**    | Concreta    | turno                                                       | mostrarDatos()                                                                                                                  | Personal administrativo de apoyo en la recepción                                |
| **SonidoAnimal**     | Interfaz    |                                                             | emitirSonido()                                                                                                                  | Interfaz la emisión de sonido para perro, gato y ave                            |
| **Mascota**          | Abstracta   | nombreMascota, edad, peso, dueno, historial                 | emitirSonido(), mostrarDatosAnimal()                                                                                            | Clase padre jerárquica para los diferentes tipos de animales                    |
| **Perro**            | Concreta    | raza, nivelEnergia                                          | mostrarDatosAnimal(), emitirSonido()                                                                                            | Subclase que modela atributos y comportamiento canino                           |
| **Gato**             | Concreta    | esDomestico                                                 | mostrarDatosAnimal(), emitirSonido()                                                                                            | Subclase que modela atributos y comportamiento felino                           |
| **AveExotica**       | Concreta    | longitudAlas                                                | mostrarDatosAnimal(), emitirSonido()                                                                                            | Subclase que modela características de aves exóticas                            |
| **HistorialClinico** | Concreta    | consultas                                                   | agregarConsulta(), listarConsultas()                                                                                            | Contenedor de consultas asociado por composición estricta a cada mascota        |
| **Consulta**         | Concreta    | fechaHora, diagnostico, tratamiento, servicio               | toString()                                                                                                                      | Registro clínico individual almacenado en el historial                          |
| **Consultorio**      | Concreta    | numero                                                      | toString()                                                                                                                      | Espacio físico dentro de la clínica asignado a las citas                        |
| **Clinica**          | Concreta    | nombre, consultorios, veterinarios, citas, duenos, mascotas | registrarDueno(), registrarMascota(), agendarCita(), atenderCita(), generarComprobante(), totalCobradoPor(), darDeBajaMascota() | Controlador central que administra y coordina todo el sistema y sus colecciones |
| **Cita**             | Concreta    | mascota, veterinario, consultorio, fechaHora, estado        | atender(), cancelar(), getFechaHora(), getEstado()                                                                              | Relaciona a la mascota, veterinario, consultorio y fecha de atención            |
| **EstadoCita**       | Enumeración | PROGRAMADA, ATENDIDA, CANCELADA                             | (Constantes de estado)                                                                                                          | Define de forma segura los estados posibles del ciclo de una cita               |
| **Facturable**       | Interfaz    |                                                             | calcularCosto()                                                                                                                 | Interfaz para calcular costo de consulta, vacunacion y cirugia                  |
| **Servicio**         | Abstracta   |                                                             | describirServicio(), calcularCosto()                                                                                            | Clase abstracta base para tipificar los cobros médicos                          |
| **ConsultaGeneral**  | Concreta    | TARIFA_BASE                                                 | describirServicio(), calcularCosto()                                                                                            | Representa un servicio de revisión médica estándar                              |
| **Vacunacion**       | Concreta    | nombreVacuna, costoVacuna                                   | describirServicio(), calcularCosto()                                                                                            | Servicio específico para la aplicación de vacunas                               |
| **Cirugia**          | Concreta    | complejidad, horasQuirofano                                 | describirServicio(), calcularCosto()                                                                                            | Servicio complejo calculado en función de la duración y complejidad             |
| **Comprobante**      | Concreta    | contadorGenerados, total, fechaHora, cita                   | getTotal(), toString()                                                                                                          | Documento de facturación generado al finalizar una cita atendida                |
